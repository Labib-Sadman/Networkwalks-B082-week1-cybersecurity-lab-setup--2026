## My First Cybersecurity Lab Setup

**Purpose:**
An isolated, controlled environment for cybersecurity learning and authorized security testing — network scanning, vulnerability assessment, packet analysis, web security testing, and tool practice.

**Steps:**

1. Download and install 7-Zip (for extracting files/tools later)
2. Download and install VirtualBox (to run isolated virtual machines)
3. Configure network settings in VirtualBox (create a NAT Network in 10.0.0.0/24)
4. Download and import the Kali Linux virtual machine into VirtualBox
5. Set up the IP configuration on Kali Linux
6. Take a snapshot of the VM

**Why take a snapshot of the VM?**

- Saves the current state of the VM so I can go back to it anytime
- Lets me test risky tools or exploits without worrying about damaging the system
- If something breaks, I can quickly restore instead of reinstalling everything
- Gives me a clean starting point before trying new labs or exercises!
